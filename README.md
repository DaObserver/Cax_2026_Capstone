## 🧠 Overview

AI Class Companion simulates a personalized tutor by turning static course content into active learning experiences:

- 🧾 Summarized lesson breakdowns  
- 💡 Simple AI explanations  
- 🧩 Fill-in-the-blank practice mode  
- 🧠 Reinforcement learning workflow
